## 后续在线课程能力

| 功能 | 状态 | 验收边界 |
| --- | --- | --- |
| 每课专属在线学习界面 | 下一步 | 每个 `Sx-xx` 均有与目标对应的学习活动、过程演示/最小示例、进度反馈与资源异常说明 |
| 每课配套视频课件 | 下一步 | 每个课程有可播放视频、章节定位、字幕或文字稿、课程 ID 和合法来源记录 |
| 随机在线测试 | 下一步 | 每次从已审校题库随机组卷；选择题数量严格多于非选择题；完成后展示得分、解析和复习出口 |
| 题库与组卷质量控制 | 下一步 | 每道题关联课程目标、难度、题型、答案和解析；同次不重复，试卷可用种子或试卷标识复现 |
| 学习尝试恢复 | 下一步 | 网络、资源或保存失败时不伪造成功；恢复后可继续本次学习或重新开始，并说明数据状态 |
| 可复制的代码模板与错误对照 | 下一步 | 帮助初学者辨识常见 C++ 错误；不在浏览器端执行不受控代码 |
| 教师备课打印版 | 下一步 | 便于课堂使用；默认不包含学生账号或行为追踪 |
| 可选的公开静态发布 | 下一步 | 让课程入口易于访问；不改变零在线判题、零个人画像的边界 |

## 不做

- 在线编译、执行或评测任意用户 C++ 代码
- 账号体系、排名、班级社交、公开作答和个人画像
- 未标记来源的大量题目转载或“保过”式承诺
- 未经审校或无法复现的随机试题、答案和解析
- 以高级竞赛算法替代零基础 C++ 核心训练

## 内容发布检查

新增或修改一节课前，确认：

- [ ] 课程的目标、内容、检验项和练习出口都已写入 `courseData`。
- [ ] 课程规划中有相同的课次和范围表述。
- [ ] 新概念具有可运行的最小示例和至少一个边界条件。
- [ ] CSP-J 必会内容与拓展内容已明确区分。
- [ ] 若课程上线互动界面、视频或测试，三项资源均有课程 ID 和学习目标对应关系。
- [ ] 若新增题目，已写明题型、难度、答案、解析和可追溯来源；每次随机组卷仍以选择题为主。
- [ ] `npm test` 通过。
- [ ] 相关手工 E2E 已按 `tests/e2e/manual-checklist.md` 执行，并更新验收矩阵（如涉及一级功能）。
