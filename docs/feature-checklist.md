# 功能清单

状态说明：`已完成` 表示首版已在仓库中落地；`下一步` 表示已确认方向但尚未承诺具体实现；`不做` 表示受项目边界约束。

## 首版交互课件

| 功能 | 状态 | 验收结果 |
| --- | --- | --- |
| 五阶段学习路径 | 已完成 | 可切换阶段并查看阶段目标与课程数量 |
| 40 节 CSP-J C++ 课件目录 | 已完成 | 每节含目标、内容、检验清单、视频组织建议和练习建议 |
| 单课件详情阅读 | 已完成 | 点击任意课件卡片即可切换详情；键盘上下方向键也可切换 |
| 交互动作反馈 | 已完成 | 切换阶段、选择课件、筛选和修改进度后显示即时状态提示 |
| 逐项学习检验 | 已完成 | 可勾选、撤销勾选或一键完成当前课 |
| 本地进度保存 | 已完成 | 刷新后恢复；浏览器拒绝存储时会给出提示且不崩溃 |
| 课程结构校验 | 已完成 | `npm test` 校验课程数据的完整性和阶段均衡 |
| 手工 E2E 验收 | 已完成 | 见 `tests/e2e/manual-checklist.md` |
| 手机端阅读 | 已完成 | 阶段栏和课程列表在窄屏下纵向重排 |

## 下一步能力

| 功能 | 价值边界 |
| --- | --- |
| 每课录课脚本与镜头卡 | 让教师可直接按“引入 - 演示 - 练习 - 检验”录制；不能替代对题目的人工讲解 |
| 可复制的代码模板与错误对照 | 帮助初学者辨识常见 C++ 错误；不在浏览器端执行不受控代码 |
| 小练习与解题过程卡 | 用少量高质量题目巩固概念；不扩张为题海或在线判题系统 |
| 教师备课打印版 | 便于课堂使用；默认不包含学生账号或行为追踪 |
| 可选的 GitHub Pages 发布 | 让公开静态课件易于访问；不改变零后端、零个人数据的边界 |

## 不做

- 在线编译、执行或评测任意用户 C++ 代码
- 账号体系、排名、班级社交、公开作答和个人画像
- 未标记来源的大量题目转载或“保过”式承诺
- 以高级竞赛算法替代零基础 C++ 核心训练

## 内容发布检查

新增或修改一节课前，确认：

- [ ] 课程的目标、内容、检验项和练习出口都已写入 `courseData`。
- [ ] 课程规划中有相同的课次和范围表述。
- [ ] 新概念具有可运行的最小示例和至少一个边界条件。
- [ ] CSP-J 必会内容与拓展内容已明确区分。
- [ ] `npm test` 通过。
- [ ] 相关手工 E2E 已按 `tests/e2e/manual-checklist.md` 执行，并更新验收矩阵（如涉及一级功能）。
