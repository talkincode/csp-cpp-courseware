# S2-07 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s2-07/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s2-07-progress-v1` 后刷新。

## E2E-S2-07-01 引导任务推进

1. 在任务 1 为“1 到 3 该怎么找偶数？”选择“从 1 数到 3，每个都看一遍”，为“过程中要记住什么？”选择“已经数到几个偶数”。先故意选一个错误说法。
2. 在任务 2 依次点击“看 i=1，奇数不加”“看 i=2，偶数加一”“看 i=3，确认结果 1”。尝试跳过第一步直接点第二步。
3. 走完“看 i=3，确认结果 1”后，在露出的一空里亲手敲入“遇到偶数就把 evenCount 加一”的那一行并点检查。先试空提交、全角括号 `if（i ％ 2 == 0）evenCount＋＋；`、只加一不判断的 `evenCount++;`、用整除去判偶数的 `if (i / 2 == 0) evenCount++;`、条件写反的 `if (i % 2 == 1) evenCount++;`、单个 `=` 的 `if (i % 2 = 0) evenCount++;`、漏末尾分号，以及把 `evenCount` 写成 `count`，再用提示和参考代码对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“按题意一步步更新 evenCount”，以及“每个 i 都要走到，漏掉 2 就会少算”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么随便猜不会数对、递归栈/搜索树/DFS 是现在不必会的拓展；**确认结果 1 之后必须亲手写出 `if (i % 2 == 0) evenCount++;` 才能进入任务 3**，空提交给出“先写出遇到偶数时更新计数的那一行”的指正，全角符号提示“小括号、百分号和分号都要半角”，`evenCount++;` 点出少了判断、奇数 1 和 3 也会被数进去（漏分支），`i / 2 == 0` 说明整数除法下 3 / 2 是 1 不是 0、判不出偶数，`i % 2 == 1` 提醒偶数取模才是 0，单个 `=` 提醒比较要用 `==`，漏分号会点名缺的是分号，写成 `count` 会提醒变量名是 `evenCount`；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；对照卡片从“i 还没走, evenCount=0”变为“i=1, evenCount=0”，再变为“i=2, evenCount=1”，最后变为“evenCount = 1”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。搜索树、DFS、剪枝和递归枚举只作为拓展出现。

补充：点击尚未点亮的任务或跳过“看 i=1，奇数不加”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S2-07-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S2-07-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认枚举范围选择、1 到 3 状态流程、**`if (i % 2 == 0) evenCount++;` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S2-07-04 常见问题解惑

1. 在任务 1 点击带虚线的 `枚举` 或 `枚举范围`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，走完三步对照，点击脚手架上方说明里的 `状态更新` 与 `取模`，确认两处都能打开词条。
4. 再点右上角“常见问题”，切换到 `模拟` 或 `漏分支`。

**预期：** 解释只用初学者能懂的话；不要求背搜索树或剪枝；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
