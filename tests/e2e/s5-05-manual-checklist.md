# S5-05 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-05/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-05-progress-v1` 后刷新。

## E2E-S5-05-01 先选出该怎么开始

1. 在任务 1 为“模拟赛有 T1（简单）、T2（中等）、T3（难题）三道题……拿到题目后，第一件事应该做什么？”选择“先用几分钟浏览全部题目，估算把握程度，排出提交顺序：有把握的先做，难题放后面”，为“写完（或决定放弃）一道题之后，应该怎么处理？”选择“在自测表里记录测过哪些数据、结果如何，并记下花费的时间；没测完的也要写清原因”。先故意选一个错误说法，确认能看到风险提示。
2. 在任务 2 依次点击“浏览排序：排出提交顺序”“自测记录：填写自测表”“时间检查：查看时间记录”。尝试跳过第一步直接点第二、三步。
3. 在任务 3 先判断时间不够时该怎么办（选择“先回头检查前面题目的自测表……把能确定的分数先保住”），再选择“如实记录哪组数据没测、原因是时间不够，方便考后复盘”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如按题号硬写、挑最难的先做、完全不记录、伪装成已测试、删掉未测记录）；对照卡片从“还没排出提交顺序”依次变为“已排出提交顺序”“已填写自测表”“已查看时间记录”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务或跳过“浏览排序：排出提交顺序”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S5-05-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-05-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-05-04 常见问题解惑

1. 在任务 1 点击带虚线的 `模拟赛`、`提交顺序`、`自测表` 或 `时间记录`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到其余词条。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧。外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
