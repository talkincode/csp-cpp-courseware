# S5-05 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-05/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-05-progress-v1` 后刷新。

## E2E-S5-05-01 引导任务推进

1. 在任务 1 为“模拟赛有 T1（简单）、T2（中等）、T3（难题）三道题……拿到题目后，第一件事应该做什么？”选择“先用几分钟浏览全部题目，估算把握程度，排出提交顺序：有把握的先做，难题放后面”，为“写完（或决定放弃）一道题之后，应该怎么处理？”选择“在自测表里记录测过哪些数据、结果如何，并记下花费的时间；没测完的也要写清原因”。先故意选一个错误说法，确认能看到风险提示。
2. 在任务 2 依次点击“浏览排序：排出提交顺序”“自测记录：填写自测表”“时间检查：查看时间记录”。尝试跳过第一步直接点第二、三步。
3. 在任务 2 出现的只读脚手架里亲手补空：`cin >> n;` 之后、`int sum = 0;` 之前的那一格要写空数据保护——`n` 等于 `0` 时输出 `0` 并马上结束程序。先空着点“检查这一空”，再输入全角写法 `if （n ＝＝ 0） ｛ … ｝`，再输入边界写错的写法 `if (n == 1) { … }`，最后写对 `if (n == 0) { cout << 0 << "\n"; return 0; }`。
4. 在任务 3 先判断时间不够时该怎么办（选择“先回头检查前面题目的自测表……把能确定的分数先保住”），再选择“如实记录哪组数据没测、原因是时间不够，方便考后复盘”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如按题号硬写、挑最难的先做、完全不记录、伪装成已测试、删掉未测记录）；对照卡片从“还没排出提交顺序”依次变为“已排出提交顺序”“已填写自测表”“已查看时间记录”；页面标明必会、建议掌握和拓展（如实记录未测原因只作拓展，不当硬门槛）；手写那一空答对后给出“进入任务 3”的反馈；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：任务 2 三步没点完时输入框不出现；点击尚未点亮的任务，或跳过“浏览排序：排出提交顺序”“自测记录：填写自测表”直接点“时间检查：查看时间记录”时，页面必须解释当前缺少哪一步，不能无反馈；三步走完并且那一空答对之后，任务 3 才点亮，任务 3 两个选择都答对后任务 4（随机小测）才点亮。空提交、全角符号、把 `n == 0` 写成 `n == 1` 或 `n = 0` 都只给具体指正，不算完成。

## E2E-S5-05-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-05-03 恢复与降级

1. 完成任意任务、写好那一空或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作、手写填空答案和答题恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、手写填空的草稿与完成状态、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-05-04 常见问题解惑

1. 在课程开头或任务 1 点击带虚线的 `模拟赛`、`提交顺序`、`自测表` 或 `时间记录`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续，并在脚手架旁点击 `边界数据`、`== 比较相等`。
4. 再点右上角“常见问题”，确认其余词条仍可打开。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题；词条载入失败时会明确说明，且不影响继续做题。
