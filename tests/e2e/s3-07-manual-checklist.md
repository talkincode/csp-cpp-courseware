# S3-07 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-07/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-07-progress-v1` 后刷新。

## E2E-S3-07-01 引导任务推进

1. 在任务 1 为“栈和队列差在哪？”选择“栈是后进先出，队列是先进先出”，为“检查括号是否匹配，该用哪个？”选择“栈：后出现的左括号要先配上”。先故意选一个错误说法。
2. 在任务 2 依次点击“空栈：还没读任何括号”“读到 ( [ ，栈顶是 [”“] 弹出 [，) 弹出 (，栈空匹配”。尝试跳过第一步直接点第二步。
3. 在任务 3 先选择一个错误说法，再选择“还没读任何括号时，栈是空的”，以及“读到 ) 时栈顶是 [，配不上；队列出队仍是 1, 2, 3”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么栈/队列都有进出顺序、图上 BFS/单调栈/最短路不是现在的必会、括号不能用队列、空栈不是已经配完；对照卡片从“还没开始读括号”变为“空栈”，再变为栈顶是 `[`，最后变为 `([])` 匹配；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。图上 BFS、最短路、单调栈只作为拓展出现。

补充：点击尚未点亮的任务或跳过“空栈：还没读任何括号”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S3-07-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S3-07-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认容器选择、括号步骤和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-07-04 常见问题解惑

1. 在任务 1 点击带虚线的 `栈` 或 `队列`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `括号匹配` 或 `后进先出`。

**预期：** 解释只用初学者能懂的话；不要求背图上 BFS、最短路或单调栈；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
