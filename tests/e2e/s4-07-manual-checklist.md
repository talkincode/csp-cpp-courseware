# S4-07 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s4-07/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s4-07-progress-v1` 后刷新。

## E2E-S4-07-01 引导任务推进

1. 在任务 1 为“5 个点（0~4），边为 (0,1) (1,2) (3,4)，要频繁查询某点直接相连的点，最合适的表示方式是？”选择“邻接表：给每个点保存一份相邻点列表，比如 adj[0] = {1}”，为“DFS 从 0 出发会经过 0→1→2，如果不记录‘谁已经访问过’，可能会发生什么？”选择“可能沿着边来回访问同一个点，导致死循环或重复计数连通块”。先故意选一个错误说法。
2. 在任务 2 依次点击“邻接表：先写出每个点的邻居”“访问标记：全部设为 false”“DFS：从未访问的点数连通块”。尝试跳过第一步直接点第二步。
3. 走完“DFS：从未访问的点数连通块”之后，在露出的一空里亲手敲入防止重复访问的那一行并点检查。先试空提交、全角符号 `if（visited［u］）return；`、以及 `if (!visited[u]) return;`（条件写反）、`if (visited[u] == false) return;`（等于没来过）、`if (visited[u] = true) return;`（单个等号是赋值）、`if (visited[u]) return 0;`（void 函数不能 return 0）、`if (visited[u]) break;`（break 跳不出函数）、`if (adj[u]) return;`（该看访问标记却看了邻接表）、`if (visited[k]) return;`（用的不是当前点 u）、`visited[u] = true;`（这是登记，不是提前收工）、`return;`（少了判断条件），再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“DFS 沿一条路径尽量走到底再回头；BFS 用队列一层一层向外扩展，得到最短步数层级”，以及“从 0 出发只能访问到 {0,1,2}；遍历所有点，若某点还没访问过就再发起一次 DFS，连通块数加一”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `if (visited[u]) return;` 才能进入任务 3**，空提交给出“先在空里写出‘来过就返回’的那一行”的指正，全角符号提示“都要敲半角”，`if (!visited[u]) return;`（条件写反，第一次进 dfs 就返回）、`if (visited[u] == false) return;`（判断成没来过）、`if (visited[u] = true) return;`（单等号是赋值不是比较）、`if (visited[u]) return 0;`（void 函数里 return 0 不合法）、`if (visited[u]) break;`（break 只能跳出循环）、`if (adj[u]) return;`（看错了数组）、`if (visited[k]) return;`（参数写错）、`visited[u] = true;`（漏了提前收工）、`return;`（漏了判断条件）都会各自被点出原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么只记录边总数或拼字符串不便于查邻居、不加访问标记会重复访问、两者顺序其实不同、只跑一次 DFS 会漏掉未访问的点；对照卡片从“还没开始写邻接表”变为已写出邻接表，再变为已初始化 visited 全部为 false，最后变为“{0,1,2} 一块，{3,4} 一块；连通块数 = 2”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。BFS 层数当最短步数只作为拓展出现。

补充：点击尚未点亮的任务或跳过“邻接表：先写出每个点的邻居”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S4-07-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S4-07-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S4-07-04 常见问题解惑

1. 在任务 1 点击带虚线的 `图`、`邻接表` 或 `访问标记`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `DFS`、`BFS 直觉` 或 `连通块`。

**预期：** 解释只用初学者能懂的话；不要求背完整的图遍历算法模板或最短路实现细节；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
