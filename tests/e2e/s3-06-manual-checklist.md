# S3-06 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-06/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-06-progress-v1` 后刷新。

## E2E-S3-06-01 引导任务推进

1. 在任务 1 为“贪心选择首先要做什么？”选择“先说出一条明确的选择标准，再每一步按它选”，为“选尽可能多的不重叠活动，该用哪条标准？”选择“每次选结束最早、且不与已选冲突的活动”。先故意选一个错误说法。
2. 在任务 2 依次点击“还没选：已选空，lastEnd = 0”“先选书法 [1, 2]，lastEnd = 2”“美术冲突跳过，再选围棋 [2, 5]”。尝试跳过第一步直接点第二步。
3. 在任务 3 先选择一个错误说法，再选择“还没选任何活动，cnt = 0，lastEnd = 0”，以及“它会先拿 [1, 4]，只能选 1 个；结束最早能选 2 个”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么贪心不是凭感觉、哈夫曼树/最短路不是现在的必会、时长最长会失败、枚举 2^n 太慢；对照卡片从“还没开始选择”变为“cnt = 0，lastEnd = 0”，再变为已选书法，最后变为书法和围棋共 2 个；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。哈夫曼树、最短路只作为拓展出现。

补充：点击尚未点亮的任务或跳过“还没选：已选空，lastEnd = 0”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S3-06-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S3-06-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认规则选择、选活动步骤和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-06-04 常见问题解惑

1. 在任务 1 点击带虚线的 `贪心选择` 或 `选择标准`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `反例` 或 `排序后决策`。

**预期：** 解释只用初学者能懂的话；不要求背哈夫曼树或最短路；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
