# S4-06 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s4-06/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s4-06-progress-v1` 后刷新。

## E2E-S4-06-01 引导任务推进

1. 在任务 1 为“4 个位置的金额 3 7 4 6，不能选相邻两个位置，要求最大总和，该怎么定义状态最合适？”选择“定义 dp[i] 为考虑前 i 个位置（不选相邻）能拿到的最大金额”，为“确定用 dp[i] 表示前 i 个位置的最优解后，第 i 个位置该怎么决策？”选择“选或不选：选它就是 dp[i-2]+nums[i]，不选就是 dp[i-1]，取较大值”。先故意选一个错误说法。
2. 在任务 2 依次点击“状态：先写出 dp[i] 的含义”“初始化：填 dp[0] 和 dp[1]”“转移：推到 dp[3]”。尝试跳过第一步直接点第二步。
3. 在任务 3 先选择一个错误说法，再选择“按 dp[i] = max(dp[i-1], dp[i-2]+nums[i]) 从小到大递推，复杂度大约 O(n)”，以及“n=1 时 dp[0] = nums[0] 就是答案；i-2 越界时不能凭空访问，要靠 dp[0]、dp[1] 的初值兜底”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么枚举所有选法在 n 变大时会指数级超时、贪心可能漏掉更优解、选中当前位置未必最优、永远跳过会漏掉更优解；对照卡片从“还没开始定义状态”变为已定义 dp[i] 含义，再变为已初始化 dp[0]=3、dp[1]=7，最后变为 dp = [3, 7, 7, 13]，dp[3] = 13；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。状态压缩只作为拓展出现。

补充：点击尚未点亮的任务或跳过“状态：先写出 dp[i] 的含义”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S4-06-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S4-06-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S4-06-04 常见问题解惑

1. 在任务 1 点击带虚线的 `状态` 或 `选或不选`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `转移`、`初始化`、`最优子结构` 或 `状态压缩`。

**预期：** 解释只用初学者能懂的话；不要求背二维背包或状态压缩的实现细节；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
