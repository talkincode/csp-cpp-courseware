# S4-08 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s4-08/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s4-08-progress-v1` 后刷新。

## E2E-S4-08-01 引导任务推进

1. 在任务 1 为“一道题拆成两个子任务：子任务 1（n≤1000，30 分，暴力可过）、子任务 2（n≤100000，70 分，需要 O(n log n)）。你只会写暴力，应该先做什么？”选择“先写暴力，保证覆盖子任务 1 拿到 30 分，再尝试优化冲子任务 2”，为“比赛只剩 10 分钟，优化版本还没调试通过，暴力版本本地能跑，应该怎么做？”选择“提交能跑的暴力保底方案，保住子任务 1 的 30 分”。先故意选一个错误说法。
2. 在任务 2 依次点击“划分：写出每个子任务的范围”“保底：先写暴力并测试通过”“冲刺：尝试优化，兜底不丢分”。尝试跳过第一步直接点第二步。
3. 走完“冲刺：尝试优化，兜底不丢分”之后，在露出的一空里亲手敲入子任务 1 的保底分支并点检查。先试空提交、全角符号 `if（n ＜= 1000）｛cout ＜＜ brute（n）；return 0；｝`、以及 `if (n <= 1000) { cout << brute(n); }`（漏了收尾的 return 0;）、`if (n <= 1000) cout << brute(n); return 0;`（少了花括号）、`if (n <= 1000) { return 0; cout << brute(n); }`（先返回就永远算不出答案）、`if (n >= 1000) { cout << brute(n); return 0; }`（方向反了）、`if (n <= 100000) { cout << brute(n); return 0; }`（写成了子任务 2 的上限，暴力会超时）、`if (n < 1000) { cout << brute(n); return 0; }`（少了等号，n = 1000 被漏掉）、`if (n <= 100) { cout << brute(n); return 0; }`（范围收得太窄，白丢子任务 1 的分）、`if (n <= 1000) { cout << fast(n); return 0; }`（保底分支却调了没把握的优化版）、`while (n <= 1000) { cout << brute(n); return 0; }`（保底判断该用 if）、`cout << brute(n); return 0;`（少了范围判断），再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“先完成有把握、分值明确的子任务，再挑战更难的子任务”，以及“留出时间重新跑一遍保底方案，确认它没有被后续修改的代码破坏”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `if (n <= 1000) { cout << brute(n); return 0; }` 才能进入任务 3**，空提交给出“先在空里写出子任务 1 的保底分支”的指正，全角符号提示“都要敲半角”，`if (n <= 1000) { cout << brute(n); }`（漏了 return 0;）、`if (n <= 1000) cout << brute(n); return 0;`（少了花括号）、`if (n <= 1000) { return 0; cout << brute(n); }`（语句顺序反了）、`if (n >= 1000) { ... }`（方向反了）、`if (n <= 100000) { ... }`（这是子任务 2 的上限，n 到 10 万时暴力会超时）、`if (n < 1000) { ... }`（少了等号，n = 1000 没被包含）、`if (n <= 100) { ... }`（范围比子任务 1 还窄）、`if (n <= 1000) { cout << fast(n); return 0; }`（保底分支该用有把握的 brute）、`while (...)`（保底判断该用 if）、`cout << brute(n); return 0;`（漏了范围判断）都会各自被点出原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么只钻研最优解、不提交、不留退路、删掉保底方案、先做最难子任务、不检查保底方案都有风险；对照卡片从“还没开始划分子任务”变为已划分子任务范围，再变为已写好保底方案，最后变为“暴力保底已提交（≥30 分）；优化版本若调通可冲到 100 分”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。复杂度降级只作为拓展出现。

补充：点击尚未点亮的任务或跳过“划分：写出每个子任务的范围”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S4-08-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S4-08-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S4-08-04 常见问题解惑

1. 在任务 1 点击带虚线的 `子任务`、`部分分` 或 `保底方案`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `先易后难`、`复杂度降级`。

**预期：** 解释只用初学者能懂的话；不要求背完整的评测系统实现或最优算法证明；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
