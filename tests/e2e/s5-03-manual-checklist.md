# S5-03 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-03/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-03-progress-v1` 后刷新。

## E2E-S5-03-01 诊断故障卡与改型三步

1. 在任务 1 为“`int total = 30000 * 30000;` 编译能过，但 total 变成了负数，这是为什么？”选择“int 装不下这么大的乘积，发生了溢出，应改成 long long”，为“数组 a 长度是 n……跑到最后一次就崩溃，这是为什么？”选择“合法下标是 0 到 n-1，i == n 时 a[i] 已经越界”。先故意选一个错误说法，确认能看到风险提示。
2. 在任务 2 依次点击“定位：找出哪个变量的类型装不下结果”“改型：把 sum 和中间量都换成 long long”“回归：用最大和最小数据各验证一次”。尝试跳过第一步直接点第二、三步。
3. 在任务 3 先选择一个错误说法，再选择“把 == 写成了 =，= 是赋值不是比较，赋值结果永远为真”，以及“删掉多余的提示语，只留答案，再用原样例回归一次”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么这不是越界/溢出/优先级问题都有对应说明；对照卡片从“还没开始定位溢出点”变为已定位，再变为已改型，最后变为“已回归：最大数据和最小数据都验证通过”；页面标明必会和建议掌握；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务或跳过“定位：找出哪个变量的类型装不下结果”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S5-03-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-03-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-03-04 常见问题解惑

1. 在任务 1 点击带虚线的 `溢出`、`初始化` 或 `数组越界`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `运算优先级`、`== 比较相等`、`long long`、`干净输出`。

**预期：** 解释只用初学者能懂的话；不要求背编译器内部细节或范围表。外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
