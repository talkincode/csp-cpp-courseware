# S3-04 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-04/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-04-progress-v1` 后刷新。

## E2E-S3-04-01 引导任务推进

1. 在任务 1 为“sum[i] 表示什么？”选择“从第 1 个到第 i 个数的累计和”，为“查询区间 [l, r] 的和该用哪条公式？”选择“sum[r] - sum[l - 1]”。先故意选一个错误说法。
2. 在任务 2 依次点击“sum[1] = 2，从第一个数开始”“sum[2] = 7，再加上 a[2] = 5”“填完 sum[4] = 12，可以开始查询”。尝试跳过第一步直接点第二步。
3. 在任务 3 先选择一个错误说法，再选择“查 [2, 4] 要用 sum[4] - sum[1]”，以及“l=1 时减的是 sum[0]，它等于 0”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么 sum[i] 不是第 i 个数、树状数组/二维前缀和不是现在的必会、sum[r]-sum[l] 会漏掉 a[l]；对照卡片从“还没开始填表”变为“sum[1] = 2”，再变为“sum[2] = 7”，最后变为“sum = [0, 2, 7, 8, 12]，可以开始查询”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。二维前缀和、差分数组、树状数组只作为拓展出现。

补充：点击尚未点亮的任务或跳过“sum[1] = 2，从第一个数开始”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S3-04-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S3-04-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认定义选择、填表步骤和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-04-04 常见问题解惑

1. 在任务 1 点击带虚线的 `前缀和` 或 `前缀和数组`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `区间和` 或 `下标偏移`。

**预期：** 解释只用初学者能懂的话；不要求背二维前缀和或树状数组；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
