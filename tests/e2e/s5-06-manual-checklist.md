# S5-06 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-06/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-06-progress-v1` 后刷新。

## E2E-S5-06-01 引导任务推进

1. 在任务 1 为“模拟赛结束后发现 T2 只拿到部分分。复盘时第一件事应该做什么？”选择“先判断这处失分属于读题错、算法错、实现错、边界错还是时间错中的哪一种，再决定怎么改”，为“给这处失分分类之后，应该怎么处理？”选择“给这一类错误写一条具体、下次能照做的改法”。先故意选一个错误说法，确认能看到风险提示。
2. 在任务 2 依次点击“找错：重新跑一遍样例和边界数据”“归类：定位到五种错误之一”“写改法并重做关键题”。尝试跳过第一步直接点第二、三步。
3. 在任务 2 出现的只读脚手架里亲手补空：`for (int i = 1;` 与 `; i += 1)` 之间那一格要写让循环走到最后一个下标 `n` 的条件。先空着点“检查这一空”，再输入全角写法 `i ＜= n`，再输入漏掉最后一个下标的写法 `i < n`，最后写对 `i <= n`。
4. 在任务 3 先判断复盘时间不够时该怎么办（选择“优先给丢分最多的几道题分类、写改法……”），再选择“如实标注‘暂不确定属于哪一类’，留到下次复盘或请教时再确认”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如抄答案不分析、只看分数不看错在哪、模糊提醒、拖到考前再想改法、必须分类完所有题、随便凑一个类别、跳过不写说明）；对照卡片从“还没找出具体错在哪”依次变为“已找出具体错在哪”“已归类”“已写下改法并重做验证”；页面标明必会、建议掌握和拓展（如实标注拿不准的分类只作拓展，不当硬门槛）；手写那一空答对后给出“进入任务 3”的反馈；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：任务 2 三步没点完时输入框不出现；点击尚未点亮的任务，或跳过“找错：重新跑一遍样例和边界数据”“归类：定位到五种错误之一”直接点“写改法并重做关键题”时，页面必须解释当前缺少哪一步，不能无反馈；三步走完并且那一空答对之后，任务 3 才点亮，任务 3 两个选择都答对后任务 4（随机小测）才点亮。空提交、全角符号、写成 `i < n` 或 `i > n`、`i = n` 都只给具体指正，不算完成。

## E2E-S5-06-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-06-03 恢复与降级

1. 完成任意任务、写好那一空或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作、手写填空答案和答题恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、手写填空的草稿与完成状态、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-06-04 常见问题解惑

1. 在课程开头或任务 1 点击带虚线的 `错误分类`、`边界数据`、`改法` 或 `重做关键题`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续，并在脚手架旁点击 `循环变量`、`下标偏移`。
4. 再点右上角“常见问题”，切换到 `错误分类`，确认能打开。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题；词条载入失败时会明确说明，且不影响继续做题。

## 自动化复验记录

E2E-S5-06-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
CSP_E2E_LESSONS=s5-06 bun tests/e2e/s2-typed-cdp.ts
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。`bun run e2e:s5-typed` 会一次覆盖 S5-01 至 S5-08 八课（112 项检查），`bun run e2e:typed` 覆盖全部 32 节已迁移课（448 项检查）。
