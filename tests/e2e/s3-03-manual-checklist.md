# S3-03 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-03/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-03-progress-v1` 后刷新。

## E2E-S3-03-01 引导任务推进

1. 在任务 1 为“在 [1, 3, 5, 7, 9] 里找 7，什么时候才能二分？”选择“数组已经从小到大排好，具有单调性”，为“left 和 right 表示什么？”选择“它们夹住还可能有答案的区间”。先故意选一个错误说法。
2. 在任务 2 依次点击“看中点 a[2] = 5，5 < 7，left 移到 3”“看中点 a[3] = 7，找到目标”“再测首尾：1 和 9 也必须能查到”。尝试跳过第一步直接点第二步。
3. 走完“再测首尾：1 和 9 也必须能查到”之后，在露出的一空里亲手敲入中点算式并点检查。先试空提交、全角括号加号除号 `（left ＋ right）／ 2`、以及 `left + right / 2` 这种漏括号的写法，再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“目标可能在 a[0] 或 a[n-1]，首尾都要能测到”，以及“比较后 left 或 right 必须移动，否则会死循环”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `(left + right) / 2` 才能进入任务 3**，空提交给出“先写下中点算式”的指正，全角括号加号除号提示“都要敲半角”，`left + right / 2`（漏括号，中点会偏）与乘 2（跑出区间）直接点出原因，更安全的写法 `left + (right - left) / 2` 会被标为拓展但同样接受；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么没排序/线段树/三分查找不是现在的必会；对照卡片从“还没开始缩小”变为“left = 3，right = 4，丢掉了 1、3、5”，再变为“left = 3，right = 4，a[3] = 7”，最后变为“找到 7，并确认 1 和 9 也要能测到”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。对答案二分、`lower_bound` 细节和三分查找只作为拓展出现。

补充：点击尚未点亮的任务或跳过“看中点 a[2] = 5，5 < 7，left 移到 3”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S3-03-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S3-03-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认前提选择、找 7 的区间收缩、**`(left + right) / 2` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-03-04 常见问题解惑

1. 在任务 1 点击带虚线的 `二分查找` 或 `单调性`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `左右边界` 或 `中点`。

**预期：** 解释只用初学者能懂的话；不要求背对答案二分或三分查找；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
