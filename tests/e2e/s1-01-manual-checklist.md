# S1-01 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-01/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-01-progress-v1` 后刷新。

## E2E-S1-01-01 引导任务推进

1. 点击“点亮 main 入口”。
2. 在编译流程中依次点击“写入源文件”“开始编译”“运行程序”。
3. 在分号排错中先选择一个错误选项，再选择“在输出行末尾添加 ;”，然后在露出的一空里亲手敲入半角分号并点“检查这个分号”。试一次空提交和中文分号，再看提示、参考代码与重置。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么不能修复；选对修复后必须亲手敲入分号才能完成任务，空提交、中文分号与多余字符都有少儿友好的指正；运行后终端区域显示 `Hello, CSP!`；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。

补充：点击尚未点亮的任务或跳过“写入源文件”直接点击“开始编译”时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S1-01-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题的检查目标都是本课学习目标原文，下一行还有更细的本题检查，另有四个选项、一个正确答案和解析；提交后显示逐题正误与得分，没通过时还会说出错题集中在哪条学习目标上、并提示回看本节讲解再换一套；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S1-01-05 题库异常降级

1. 在开发者工具中把该页内联脚本里的 `questionPool` 临时改成 `[]`，刷新页面后进入“随机小测”。
2. 恢复题库，再把任意一题的 `answer` 改成超出选项范围的值（例如 4 个选项时写成 `answer: 99`），刷新页面后进入“随机小测”。

**预期：** 两种情况都显示“题库暂时不可用或题目无效”的说明和“无法组卷”提示，提交按钮不可点击；任务进度、本地存储与常见问题互动继续可用，不出现白屏或伪造的分数。

## E2E-S1-01-03 恢复与降级

1. 完成任意任务、在补分号框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认流程、补分号草稿和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-01-04 常见问题解惑

1. 在任务 1 点击带虚线的 `main`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击终端或课文中的 `g++`。
4. 再点右上角“常见问题”，切换到 `.cpp 源文件`。

**预期：** 解释只用初学者能懂的话；`g++` 被说明为编译器命令，而不是要求背参数；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。

## E2E-S1-01-06 会话中途保存失败与恢复

1. 进入“随机小测”，先不要作答。
2. 在开发者工具控制台让写入开始失败：

   ```js
   Storage.prototype.setItem = () => { throw new DOMException("quota", "QuotaExceededError"); };
   ```

3. 选择任意一道题的答案。
4. 恢复写入（`delete Storage.prototype.setItem`），再点击提示里的“重试保存”。

**预期：** 第 3 步后页面立刻出现“刷新页面后不会恢复进度”的说明和“重试保存”按钮；已选答案在当前会话里保持选中，互动不中断；顶部提示条随后仍会被正常操作提示覆盖，但保存失败的说明必须留在页面上；本地存储里不会出现这条答案（不伪造已保存）。第 4 步点击重试后提示消失，顶部说明“本地保存已恢复”，并且刚才的答案被补写进本地存储。

## E2E-S1-01-07 词条载入失败与恢复

1. 在开发者工具的网络面板里屏蔽 `/glossary/faq.json`，刷新页面。
2. 点击课文里带虚线的 `main`，再点右上角“常见问题”。
3. 取消屏蔽，点击面板里的“重新载入词条表”。

**预期：** 第 2 步面板当场说明词条表无法载入，给出“重新载入词条表”入口和“继续学习”出口，不把失败说成“正在载入”；此时任务按钮、进度与小测仍然可用。第 3 步重载成功后入口收起、词条列表回来，并直接显示刚才点开的 `main` 解释与“现在记住”。
