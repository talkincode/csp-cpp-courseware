# S3-08 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-08/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-08-progress-v1` 后刷新。

## E2E-S3-08-01 引导任务推进

1. 在任务 1 为“动态规划在本课是什么意思？”选择“用已经算好的小问题推出更大的问题”，为“爬楼梯里 dp[i] 表示什么？”选择“走到第 i 级台阶的方法数”。先故意选一个错误说法。
2. 在任务 2 依次点击“初值：dp[1] = 1”“再写 dp[2] = 2”“转移：dp[3] = dp[2] + dp[1] = 3”。尝试跳过第一步直接点第二步。
3. 走完“转移：dp[3] = dp[2] + dp[1] = 3”之后，在露出的一空里亲手敲入转移语句并点检查。先试空提交、全角方括号等号加号 `dp［i］＝dp［i － 1］＋dp［i － 2］`、以及 `dp[i] = dp[i - 1] * dp[i - 2]` 这种把两类走法相乘的写法，再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“必须先写 dp[1] = 1 和 dp[2] = 2，才能推 dp[3]”，以及“n=1 时答案就是 dp[1] = 1；状态压缩现在不是硬门槛”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `dp[i] = dp[i - 1] + dp[i - 2]` 才能进入任务 3**，空提交给出“先在空里写出转移那一行”的指正，全角方括号等号加号提示“都要敲半角”，用乘号（两类走法该相加）、把 `i - 1` 写两次（漏了从 `i - 2` 一次走 2 级）、多写 `+ 1`、等号右边又用了 `dp[i]` 自己（这一格还没算出来）、写成 `dp[i + 1]`（跳过了第 i 级），这七种写法都会被点出各自的原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么不能先猜全部答案、状态压缩/二维背包/树形 DP 不是现在的必会、`dp[i]` 不是数字 i 本身、初值不能随便填、n=1 也能做；对照卡片从“还没开始填表”变为 `dp[1] = 1`，再变为两个初值，最后变为 `dp[3] = 3`；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。状态压缩、二维背包、树形 DP 只作为拓展出现。

补充：点击尚未点亮的任务或跳过“初值：dp[1] = 1”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S3-08-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S3-08-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认含义选择、手算步骤、**`dp[i] = dp[i - 1] + dp[i - 2]` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-08-04 常见问题解惑

1. 在任务 1 点击带虚线的 `动态规划` 或 `状态`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `转移` 或 `初始化`。

**预期：** 解释只用初学者能懂的话；不要求背状态压缩、二维背包或树形 DP；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
