# S1-05 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-05/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-05-progress-v1` 后刷新。

## E2E-S1-05-01 引导任务推进

1. 在任务 1 为“判断满分 100”选择 `score == 100`，为“晋级线 60 分”选择 `score >= 60`。先故意选 `score = 100` 和 `score > 60`。
2. 在任务 2 的两个微编程空里分别敲入 `score >= 90` 和 `score >= 60`。先试空提交、单个 `=`、中文括号、大写 `SCORE`。
3. 依次点“查看提示”“参考代码”“重置”，再重新敲对并点“检查两行条件”。
4. 在任务 3 先选一个错误边界，再选“60 分算合格，90 分算优秀，等于也要有去处”，以及“score >= 0 && score <= 100 检查分数在范围内”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；`=` 与 `==`、`>` 与 `>=` 的错误都有少儿友好的解释；三路走法从空白变为 `90 -> 优秀，75 -> 合格，40 -> 再复习`；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务时，页面必须解释当前缺少哪一步，不能无反馈；输入框为等宽字体，移动端不自动大写纠错，读屏可报出反馈。

## E2E-S1-05-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S1-05-03 恢复与降级

1. 完成任意任务、在微编程框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认比较选择、两空输入、边界组合和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、两空草稿、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-05-04 常见问题解惑

1. 在任务 1 点击带虚线的 `==` 或比较运算。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `==`，再点右上角“常见问题”，切换到逻辑组合。

**预期：** 解释只用初学者能懂的话；不要求背完整运算符表；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
