# S3-05 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s3-05/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s3-05-progress-v1` 后刷新。

## E2E-S3-05-01 引导任务推进

1. 在任务 1 为“left 和 right 表示什么？”选择“当前连续窗口的左端点和右端点”，为“窗口条件被破坏时该怎么办？”选择“先移动会让条件恢复的那一边，通常是 left++”。先故意选一个错误说法。
2. 在任务 2 依次点击“空窗口：left = 1, right = 0”“right = 1，纳入 a[1] = 1”“right = 2，窗口和 sum = 3”。尝试跳过第一步直接点第二步。
3. 走完“right = 2，窗口和 sum = 3”之后，在露出的一空里亲手敲入扩大窗口的两步并点检查。先试空提交、全角加号分号方括号 `right＋＋； sum ＋= a［right］；`、以及 `sum += a[right]; right++;` 这种两步顺序反了的写法，再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“空窗口时 right < left，例如 left = 1, right = 0”，以及“不要两边一起跳；先 left++ 丢掉左端，让条件恢复”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `right++; sum += a[right];` 才能进入任务 3**，空提交给出“先在空里写下扩大窗口的两步”的指正，全角加号分号方括号提示“都要敲半角”，两步顺序反了（会漏掉新纳入的数）、用减号、下标写成 `a[left]`、只移不加、只加不移、移错成 `left++`、用 `=` 覆盖窗口和、方向反成 `right--`，这八种写法都会被点出各自的原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么两个指针不是无关下标、单调队列/三数之和不是现在的必会、两边一起跳会破坏窗口；对照卡片从“还没开始移动指针”变为“left = 1, right = 0”，再变为纳入 a[1]，最后变为“left = 1, right = 2，sum = 3”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。单调队列、三数之和只作为拓展出现。

补充：点击尚未点亮的任务或跳过“空窗口：left = 1, right = 0”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S3-05-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S3-05-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认定义选择、窗口步骤、**`right++; sum += a[right];` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S3-05-04 常见问题解惑

1. 在任务 1 点击带虚线的 `双指针` 或 `滑动窗口`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `窗口条件` 或 `左指针`。

**预期：** 解释只用初学者能懂的话；不要求背单调队列或三数之和；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
