# S2-06 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s2-06/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s2-06-progress-v1` 后刷新。

## E2E-S2-06-01 引导任务推进

1. 在任务 1 为“3, 1, 2 该怎么变整齐？”选择“比较相邻两数，大的往后换”，为“两个数谁该排前面？”选择“更小的应排在前面”。先故意选一个错误说法。
2. 在任务 2 依次点击“比较 3 和 1，交换”“比较 3 和 2，交换”“确认 1, 2, 3”。尝试跳过第一步直接点第二步。
3. 走完“确认 1, 2, 3”后，在露出的一空里亲手敲入把相邻两格换过来的写法并点检查。先试空提交、全角括号 `swap（a[0], a[1]）`、换同一格的 `swap(a[0], a[0])`、跳到不相邻的格 `swap(a[0], a[2])`，以及直接赋值的 `a[0] = a[1]`，再用提示和参考代码对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“sort(a, a + n)，默认从小到大”，以及“原来在前的，排完还应在前”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么随便打乱不会变整齐、下标小不等于该排前面、或快排/lambda/NOI 稳定性证明是现在不必会的拓展；**确认 1, 2, 3 之后必须亲手写出 `swap(a[0], a[1])` 才能进入任务 3**，空提交给出“先写下把这两格换过来的写法”的指正，全角符号提示“括号和逗号都要半角”，`swap(a[0], a[0])` 点出换同一格等于没换，`swap(a[0], a[2])` 点出这两格不相邻、跳着换会漏掉，`a[0] = a[1]` 说明直接赋值会把原来那一格盖掉、两个格子会变成同一个值，漏括号或只写 `swap` 会提醒里面要写两个用半角逗号分开的格子；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；对照卡片从“3, 1, 2”变为“1, 3, 2”，再变为“1, 2, 3”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。快排、堆排、lambda 比较器和稳定性证明只作为拓展出现。

补充：点击尚未点亮的任务或跳过“比较 3 和 1，交换”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S2-06-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S2-06-03 恢复与降级

1. 完成任意任务、在交换写法框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认比较规则选择、3/1/2 交换流程、**`swap(a[0], a[1])` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S2-06-04 常见问题解惑

1. 在任务 1 点击带虚线的 `冒泡思想` 或 `比较规则`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `交换`。
4. 再点右上角“常见问题”，切换到 `sort` 或 `稳定性`。

**预期：** 解释只用初学者能懂的话；不要求背快排或稳定性证明；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。

E2E-S2-06-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
bun run e2e:s2-typed
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。脚本一次覆盖全部 16 节已迁移课（S2-01 至 S2-08、S3-01 至 S3-08），每课 14 项检查；`CSP_E2E_LESSONS=s2-06 bun tests/e2e/s2-typed-cdp.ts` 可以只跑本课。
