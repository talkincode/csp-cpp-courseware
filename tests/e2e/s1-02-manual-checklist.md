# S1-02 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-02/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-02-progress-v1` 后刷新。

## E2E-S1-02-01 引导任务推进

1. 在任务 1 为“参赛人数 30”选择 `int`，为“平均分 88.5”选择 `double`，为“等级字母 'A'”选择 `char`。先故意选一个错误类型。
2. 在任务 2 依次点击“声明变量”“第一次赋值”“更新累加”，然后在露出的一空里亲手敲入 `score = score + 15;` 并点检查。先试空提交和 `==`，再看提示、参考代码与重置。尝试跳过声明直接赋值。
3. 在任务 3 先选择一个错误说法，再选择“用 char 保存一个等级字母，例如 'A'”，以及“改用 long long，先看题目范围”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么类型不合适；变量盒子从空变为 80 再变为 95；更新演示后必须亲手写下更新语句才能完成任务，`==`、缺分号与中文符号都有指正；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务或跳过“声明变量”直接点击赋值时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S1-02-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S1-02-05 题库异常降级

1. 在开发者工具中把该页内联脚本里的 `questionPool` 临时改成 `[]`，刷新页面后进入“随机小测”。
2. 恢复题库，再把任意一题的 `answer` 改成超出选项范围的值（例如 4 个选项时写成 `answer: 99`），刷新页面后进入“随机小测”。

**预期：** 两种情况都显示“题库暂时不可用或题目无效”的说明和“无法组卷”提示，提交按钮不可点击；任务进度、本地存储与常见问题互动继续可用，不出现白屏或伪造的分数。

## E2E-S1-02-03 恢复与降级

1. 完成任意任务、在更新语句框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认类型选择、变量流程、更新语句草稿和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-02-04 常见问题解惑

1. 在任务 1 点击带虚线的 `int` 或 `char`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `变量` 或 `赋值`。
4. 再点右上角“常见问题”，切换到 `long long` 或 `溢出`。

**预期：** 解释只用初学者能懂的话；不要求背完整类型范围表；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。

## 自动化复验记录

E2E-S1-02-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
bun run e2e:s1-typed
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。`bun run e2e:s1-typed` 一次覆盖 S1-02 至 S1-08 七课（115 项检查，本课 17 项），`bun run e2e:typed` 覆盖全部 39 节已迁移课（659 项检查）；`CSP_E2E_LESSONS=s1-02 bun tests/e2e/s2-typed-cdp.ts` 可以只跑本课。

自动化覆盖的部分：输入框等宽字体与移动端防干扰属性、脚手架只留一空且没有 textarea、打开页面时输入框还没有出现、先把三个量的类型都选对，再走完「存文件 → 编译 → 运行」三步，输入框才出现、逐字符真实键盘输入会写进草稿、提示与参考代码兜底、重置会把输入框里看得见的内容和草稿一起清掉、作答正确后进入下一个任务、刷新后草稿与完成状态恢复、输入内容原样保留且不会被当成 HTML 或正确答案；抽到的题把检查目标绑到本课学习目标原文并保留本题检查。

三种失败路径（自动化逐条核对过）：空提交会提示“先写下你的答案”；整行都是全角符号时逐个指出该换成半角；第三种是写错语义 —— 写成 `score == score + 15;`（单个 `=` 才是放进变量），会给出对应指正且不判定完成。

重置按钮本轮修过：以前多数课只清掉状态，输入框里看得见的旧字会留下（聚焦状态下尤其明显），现在内容与对错样式一起清；本轮把 S1 里还漏这条的七课补齐，S1-05 本来就已经清得干净，作为对照保留。

仍需人工确认的部分：窄屏排版、键盘焦点观感、音效听感，以及上面对应场景里没被自动化覆盖的步骤。
