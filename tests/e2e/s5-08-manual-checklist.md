# S5-08 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-08/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-08-progress-v1` 后刷新。

## E2E-S5-08-01 先选出该怎么开始

1. 在任务 1 为“开始整理知识地图前，比较合理的做法是什么？”选择“先把 S1~S5 每个阶段学过的知识点列出来，再逐项标注自己是熟练、一般还是薄弱”，为“在知识地图里标注‘薄弱模块’时，比较合理的做法是什么？”选择“具体标到某个知识点（比如‘DP 状态设计’），并为它安排一次有针对性的复习”。先故意选一个错误说法（例如“跳过列清单，只凭印象回忆几个觉得薄弱的点”），确认能看到风险提示。
2. 在任务 2 依次点击“知识地图：盘点五阶段知识点”“薄弱项标记：挑出模块并安排复习”“赛前清单：确认环境与安排”。尝试跳过第一步直接点第二、三步。
3. 在任务 2 出现的只读脚手架里亲手补空：赛前清单里的「常用代码片段」挑的是计数数组，分数在 0 到 100 之间，那一格要写出统计每个分数出现几次的第一行（先把格子清零）。先空着点“检查这一空”，再输入全角写法 `int cnt［105］＝｛0｝；`，再输入 `int cnt[105] = 0;`（只设了第一个格子）、`int cnt[105];`（没清零），最后写对 `int cnt[105] = {0};`。
4. 在任务 3 先选择薄弱模块复习顺序的正确做法（“按优先级复习：先挑出现次数最多、影响面最大的薄弱模块”），再选择 CSP-S 更高级算法现在要不要学会的正确判断（“知道大致边界在哪就够了，标注为‘以后再学’，不必现在学会”）。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如只凭印象回忆会漏掉薄弱点、笼统标注“基础不好”没用、不安排复习就没解决问题、随便选顺序或只挑最难的一个不合理、现在就要学会 CSP-S 高级算法或完全不了解边界都不对）；对照卡片从“还没开始盘点知识地图”依次变为“已完成知识地图”“已标记薄弱模块”“已确认赛前清单”；页面标明必会、建议掌握和拓展；手写那一空答对后给出“进入任务 3”的反馈；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：任务 2 三步没点完时输入框不出现；点击尚未点亮的任务，或跳过“知识地图：盘点五阶段知识点”“薄弱项标记：挑出模块并安排复习”直接点“赛前清单：确认环境与安排”时，页面必须解释当前缺少哪一步，不能无反馈；三步走完并且那一空答对之后，任务 3 才点亮，任务 3 两个选择都答对后任务 4（随机小测）才点亮。空提交、全角符号、写成 `= 0`（只清第一个格子）、没写初值、格子数不够放下 0~100、漏掉 `int` 或末尾分号，都只给具体指正，不算完成；写成 `int cnt[105] = {};` 也算答对。

## E2E-S5-08-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-08-03 恢复与降级

1. 完成任意任务、写好那一空或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作、手写填空答案和答题恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、手写填空的草稿与完成状态、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-08-04 常见问题解惑

1. 在任务 1 或任务 2 点击带虚线的 `知识地图`、`薄弱模块`、`赛前检查清单`或`CSP-S 衔接条件`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，确认页面仍可继续，并在脚手架旁点击 `计数数组`、`清零`。
4. 再点右上角“常见问题”，切换到 `知识地图`，确认能打开。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧；CSP-S 相关解释只做边界说明，不展开具体教学。外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题；词条载入失败时会明确说明，且不影响继续做题。

## 自动化复验记录

E2E-S5-08-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
CSP_E2E_LESSONS=s5-08 bun tests/e2e/s2-typed-cdp.ts
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。`bun run e2e:s5-typed` 会一次覆盖 S5-01 至 S5-08 八课（112 项检查），`bun run e2e:typed` 覆盖全部 32 节已迁移课（448 项检查）。
