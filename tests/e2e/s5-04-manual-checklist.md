# S5-04 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-04/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-04-progress-v1` 后刷新。

## E2E-S5-04-01 引导任务推进

1. 在任务 1 为“区间求和题，q 次查询每次给 l、r，求 a[l..r] 的和。你还没想出前缀和，应该先做什么？”选择“先写暴力基线：每次查询直接从 l 到 r 累加，在小数据上测试通过”，为“暴力基线写完并测试通过后，应该怎么处理？”选择“标注它能处理的 n、q 范围，并写清 l>r 这类特殊情况怎么处理”。先故意选一个错误说法，确认能看到风险提示。
2. 在任务 2 依次点击“基线：写出暴力并测试通过”“标注：写清适用范围与特殊情况”“升级：换成前缀和，同时保留基线”。尝试跳过第一步直接点第二、三步。
3. 在任务 2 出现的只读脚手架里亲手补空：`cout <<` 与 `<< "\n";` 之间那一格要写查询 a[l..r] 区间和的算式。先空着点“检查这一空”，再输入全角写法 `sum［r］－sum［l－1］`，再输入漏减 1 的伪优化写法 `sum[r] - sum[l]`，最后写对 `sum[r] - sum[l - 1]`。
4. 在任务 3 先判断 `sum[r]-sum[l]` 是不是伪优化（选择“是伪优化：sum[r]-sum[l] 算错了下标，会漏掉 l 位置的值，输出会出错”），再选择“用同一组小数据，让基线和前缀和版本各跑一次，比较输出是否一致”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如只钻研前缀和、只在草稿纸上证明而不写代码、假设基线完美、直接删掉暴力基线、把 `sum[r]-sum[l]` 当成真优化或当成不影响结果）；对照卡片从“还没开始写基线”依次变为“已写基线”“已标注”“已升级为前缀和：O(n+q)，查询变成 O(1)”；页面标明必会、建议掌握和拓展（伪优化的具体识别只作拓展，不当硬门槛）；手写那一空答对后给出“进入任务 3”的反馈；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：任务 2 三步没点完时输入框不出现；点击尚未点亮的任务，或跳过“基线：写出暴力并测试通过”“标注：写清适用范围与特殊情况”直接点“升级：换成前缀和，同时保留基线”时，页面必须解释当前缺少哪一步，不能无反馈；三步走完并且那一空答对之后，任务 3 才点亮，任务 3 两个选择都答对后任务 4（随机小测）才点亮。空提交、全角符号、漏减 1 的写法都只给具体指正，不算完成。

## E2E-S5-04-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-04-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-04-04 常见问题解惑

1. 在课程开头或任务 1 点击带虚线的 `暴力基线`、`子任务` 或 `特殊情况`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续；在任务 2 点击 `复杂度升级`、`区间和`、`下标偏移`、`前缀和数组`。
4. 再点右上角“常见问题”，切换到 `差分检查`、`伪优化`。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
