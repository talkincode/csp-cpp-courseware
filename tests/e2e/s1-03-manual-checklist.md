# S1-03 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-03/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-03-progress-v1` 后刷新。

## E2E-S1-03-01 引导任务推进

1. 在任务 1 为“长 8、宽 5 的周长”选择 `2 * (length + width)`，为“a 和 b 的平均数”选择 `(a + b) / 2`，然后在露出的一空里亲手敲入 `(a + b) / 2` 并点检查。先故意选一个错误公式，再试 `a + b / 2` 与中文括号。
2. 在任务 2 依次点击“计算整除”“计算余数”“判断偶数”。尝试跳过整除直接点余数。
3. 在任务 3 先选择一个错误说法，再选择“先算除法 b / 2，所以结果是 9 不是平均数”，以及“写成 (a + b) / 2”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么公式或顺序不对；选对公式后必须亲手写下平均数算式才能进入任务 2，缺括号、相乘与中文符号都有指正；口算纸从 7 个苹果变为装满 3 盘、余下 1 个，再变为偶数余数是 0；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务或跳过“计算整除”直接点击余数时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S1-03-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S1-03-03 恢复与降级

1. 完成任意任务、在平均数算式框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认公式选择、平均数算式草稿、整除流程和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-03-04 常见问题解惑

1. 在任务 1 点击带虚线的 `表达式` 或 `括号`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `整除` 或 `取模`。
4. 再点右上角“常见问题”，切换到 `运算优先级`。

**预期：** 解释只用初学者能懂的话；不要求背完整优先级表；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
