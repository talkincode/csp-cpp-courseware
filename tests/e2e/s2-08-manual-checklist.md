# S2-08 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s2-08/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s2-08-progress-v1` 后刷新。

## E2E-S2-08-01 引导任务推进

1. 在任务 1 为“n 很大时，该怎么判断程序能不能跑完？”选择“先数循环大概跑几次”，为“两层循环套在一起，大约做几次？”选择“大约做 n × n 次”。先故意选一个错误说法。
2. 在任务 2 依次点击“看 n=3 的单层循环，大约 3 次”“看 n=3 的双层循环，大约 9 次”“确认双层更重，n 变大差更多”。尝试跳过第一步直接点第二步。
3. 走完“确认双层更重，n 变大差更多”后，在露出的一空里亲手敲入双层循环大约做多少次并点检查。先试空提交、全角乘号 `n ＊ n`、把两层并排相加的 `n + n`、只数一层的 `n`、把 `^` 当乘方的 `n ^ n`、把两层当并排翻倍的 `n * 2`、多套一层的 `n * n * n`，以及写死数字的 `1000 * 1000`，再用提示和参考代码对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“n=100000 时用单层循环更稳妥”，以及“至少测最小、最大和一组普通数据”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么代码短不等于快、两层不是大约 n 次、或严格大 O / 主定理是现在不必会的拓展；**确认双层更重之后必须亲手写出 `n * n` 才能进入任务 3**，空提交给出“先写下双层循环大约做多少次”的指正，全角乘号提示“乘号要敲半角的 `*`（Shift + 8）”，`n + n` 说明两层是套在一起、内层要整圈走完所以次数相乘，只写 `n` 说明还有一层没数进来，`n ^ n` 说明 `^` 在 C++ 里是按位异或、不是乘方，`n * 2` 说明这等于把两层当成并排、套在一起时内层每次都要走 n 次所以要乘 n，多写一层说明这个脚手架只有两层、数多了，写死 `1000 * 1000` 说明数字乘得没错但这一空要用 n 写、n 换成别的值算式还得照样能用；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；对照卡片从“还没开始数”变为“单层约 3 次”，再变为“单层约 3 次，双层约 9 次”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。严格大 O 证明、主定理和摊还分析只作为拓展出现。

补充：点击尚未点亮的任务或跳过“看 n=3 的单层循环，大约 3 次”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确算式。

## E2E-S2-08-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S2-08-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认估法选择、n=3 次数对照、**`n * n` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S2-08-04 常见问题解惑

1. 在任务 1 点击带虚线的 `操作次数` 或 `O(n)`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `测试点` 或 `边界数据`。

**预期：** 解释只用初学者能懂的话；不要求背主定理或严格大 O；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
