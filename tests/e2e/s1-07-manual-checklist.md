# S1-07 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-07/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-07-progress-v1` 后刷新。

## E2E-S1-07-01 引导任务推进

1. 在任务 1 为“输出 n 行 n 列星星”选择“外层 for 行，内层 for 列”，为“谁管行、谁管列”选择“外层管行、内层管列”，然后在露出的一空里亲手敲入 `for (int c = 1; c <= n; c++)` 并点检查。先故意选一个错误职责，再试行变量 `r` 与括号后的分号。
2. 在任务 2 依次点击“第 1 行”“第 2 行”“第 3 行”。尝试跳过第 1 行直接点第 2 行。
3. 在任务 3 先选择一个错误说法，再选择“结束当前这一层循环”，以及“在内层写 break”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么内外层或停法不对；选对职责后必须亲手写下内层循环才能进入任务 2，行列变量用错、边界与中文符号都有指正；图案卡片从“还没开始印”变为“***”，再变为两行，再变为三行九颗星；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：点击尚未点亮的任务或跳过“第 1 行”直接点击第 2 行时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S1-07-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S1-07-03 恢复与降级

1. 完成任意任务、在内层循环框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认内外层选择、内层循环草稿、3 行图案流程和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-07-04 常见问题解惑

1. 在任务 1 点击带虚线的 `嵌套循环` 或 `外层`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，点击 `break` 或 `continue`。
4. 再点右上角“常见问题”，切换到 `内层循环`。

**预期：** 解释只用初学者能懂的话；不要求背完整循环语法表；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。

## 自动化复验记录

E2E-S1-07-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
bun run e2e:s1-typed
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。`bun run e2e:s1-typed` 一次覆盖 S1-02 至 S1-08 七课（115 项检查，本课 16 项），`bun run e2e:typed` 覆盖全部 39 节已迁移课（659 项检查）；`CSP_E2E_LESSONS=s1-07 bun tests/e2e/s2-typed-cdp.ts` 可以只跑本课。

自动化覆盖的部分：输入框等宽字体与移动端防干扰属性、脚手架只留一空且没有 textarea、打开页面时输入框还没有出现、任务 1 两处写法都选对时输入框就出现、逐字符真实键盘输入会写进草稿、提示与参考代码兜底、重置会把输入框里看得见的内容和草稿一起清掉、作答正确后进入下一个任务、刷新后草稿与完成状态恢复、输入内容原样保留且不会被当成 HTML 或正确答案；抽到的题把检查目标绑到本课学习目标原文并保留本题检查。

三种失败路径（自动化逐条核对过）：空提交会提示“先写下你的答案”；整行都是全角符号时逐个指出该换成半角；第三种是写错语义 —— 写成 `r`（内层管列），会给出对应指正且不判定完成。

重置按钮本轮修过：以前多数课只清掉状态，输入框里看得见的旧字会留下（聚焦状态下尤其明显），现在内容与对错样式一起清；本轮把 S1 里还漏这条的七课补齐，S1-05 本来就已经清得干净，作为对照保留。

仍需人工确认的部分：窄屏排版、键盘焦点观感、音效听感，以及上面对应场景里没被自动化覆盖的步骤。
