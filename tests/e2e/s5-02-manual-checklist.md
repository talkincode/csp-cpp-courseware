# S5-02 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-02/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-02-progress-v1` 后刷新。

## E2E-S5-02-01 引导任务推进

1. 在任务 1 为“程序在 n=100000 上错了，样例却是对的。第一步该做什么？”选择“先构造能稳定复现错误的最小数据，再对着小数据修”，为“已经有一组 n=2 的反例，接下来该怎么验证“是下标写错了”？”选择“在可疑位置加分段输出，看中间值是不是自己想的”。先故意选一个错误说法。
2. 在任务 2 依次点击“缩小：把 n=5 的错误缩到 n=2 仍错”“分段输出：打印 i 和 prefix 对照手算”“回归：记下原因，再用样例和反例复测”。尝试跳过第一步直接点第二步。
3. 在任务 3 先选择一个错误说法，再选择“写下“这里 prefix 应该等于手算”，再对照分段输出”，以及“用原样例和这组最小反例再跑一遍；差分检查只作拓展认识”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么乱改、整份重写、只看最终答案、修完不测都有风险；对照卡片从“还没开始缩小错误范围”变为已缩小，再变为已分段输出，最后变为“已记下原因并回归：少加了 a[0]”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。差分检查只作为拓展出现。

补充：点击尚未点亮的任务或跳过“缩小：把 n=5 的错误缩到 n=2 仍错”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S5-02-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-02-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-02-04 常见问题解惑

1. 在任务 1 点击带虚线的 `系统化调试`、`最小复现` 或 `分段输出`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `断言思路`、`差分检查`。

**预期：** 解释只用初学者能懂的话；不要求背调试器或把差分检查当硬门槛；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
