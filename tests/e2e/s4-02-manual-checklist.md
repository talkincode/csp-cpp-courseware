# S4-02 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s4-02/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s4-02-progress-v1` 后刷新。

## E2E-S4-02-01 引导任务推进

1. 在任务 1 为“建模卡在本课要做什么？”选择“先写下已知、未知和目标，再写代码”，为“已知和未知怎么分？”选择“已知是题面给的量和输入；未知是要求出的答案”。先故意选一个错误说法。
2. 在任务 2 依次点击“写下已知：n 和 n 个数”“写下未知/目标：求和并输出”“样例反推：1+2+3=6”。尝试跳过第一步直接点第二步。
3. 走完“样例反推：1+2+3=6”之后，在露出的一空里亲手敲入累加那一行并点检查。先试空提交、全角符号 `sum ＋= a［i］；`、以及 `sum = a[i];` 这种每轮覆盖前面结果的写法、`sum += i;`（加的是下标）、`sum += a[0];`（每轮加的都是第一个数），再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“先列循环累加；搜索树现在不是硬门槛”，以及“n=1 时输入 7 输出 7；全是 0 输出 0”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `sum += a[i];` 才能进入任务 3**，空提交给出“先在空里写出累加那一行”的指正，全角符号提示“都要敲半角”，`sum = a[i];`（覆盖）、`sum += i;`（加下标）、`sum += a[0];`（每轮加第一个数）、`sum += a[n];`（越界）、`cin >> a[i];`（写成读入）都会各自被点出原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么不要先写完整程序再猜题意、搜索树/图论/状态压缩不是现在的必会、已知未知不能混在一起、样例反推不能跳过、n=1 和全 0 都要自己写；对照卡片从“还没开始填卡”变为已写下已知，再变为已写目标和，最后变为 1+2+3=6；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。图论、搜索树、状态压缩只作为拓展出现。

补充：点击尚未点亮的任务或跳过“写下已知：n 和 n 个数”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S4-02-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S4-02-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认建模卡选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S4-02-04 常见问题解惑

1. 在任务 1 点击带虚线的 `建模卡` 或 `已知与未知`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `样例反推` 或 `算法候选`。

**预期：** 解释只用初学者能懂的话；不要求背搜索树或状态压缩；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
