# S2-03 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s2-03/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s2-03-progress-v1` 后刷新。

## E2E-S2-03-01 引导任务推进

1. 在任务 1 为“重复判断偶数怎么写”选择“bool isEven(int x)”，为“结果怎么交回调用处”选择“return x % 2 == 0;”。先故意选一个错误写法。
2. 在任务 2 依次点击“调用 isEven(4)”“看参数 x”“看返回值”。尝试跳过调用直接点参数。
3. 在走完“看返回值”后露出的一空里亲手敲入这次调用的写法并点检查。先试空提交、全角小括号 `isEven（4）`、以及只写函数名 `isEven` 或改参数 `isEven(5)`，再用提示和参考代码对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“写成 bool isLeap(int y) 再多次调用”，以及“isLeap(2024); isLeap(2023);”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么复制粘贴、只 cout、或函数模板不对；**走完流程后必须亲手写出 `isEven(4)` 才能进入任务 3**，空提交给出“先写下调用”的指正，全角符号提示“小括号要用半角 ( )”，只写函数名会解释“函数不会自己跑起来”，大小写不符或参数不对也有具体指正；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；调用卡片从“还没开始走”变为“isEven(4)”，再变为“x = 4”，再变为“返回 true”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。函数模板、默认参数和重载只作为拓展出现。

补充：点击尚未点亮的任务或跳过“调用 isEven(4)”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S2-03-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记为已通过校验。


## E2E-S2-03-03 恢复与降级

1. 完成任意任务、在调用框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认函数写法选择、调用走格流程、**调用草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S2-03-04 常见问题解惑

1. 在任务 1 点击带虚线的 `函数` 或 `函数定义`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `调用` 或 `参数`。
4. 再点右上角“常见问题”，切换到 `返回值`。

**预期：** 解释只用初学者能懂的话；不要求背完整函数标准或模板；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
