# S2-01 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s2-01/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s2-01-progress-v1` 后刷新。

## E2E-S2-01-01 引导任务推进

1. 在任务 1 为“8 次同类训练成绩怎么存”选择“一个数组 int a[n]”，为“第一个成绩放在哪一格”选择“a[0]”。先故意选一个错误存法或错误下标。
2. 在任务 2 依次点击“看 a[0]”“看 a[1]”“看最后一个”。尝试跳过 a[0] 直接点 a[1]。
3. 走完“看最后一个”后，在露出的一空里亲手敲入访问最后一个成绩的写法并点检查。先试空提交、全角方括号 `a［n - 1］`、以及 `a[n]` 这种越界写法，再用提示和参考代码对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“先记下 a[0]，再从下标 1 走到 n - 1”，以及“for (int i = 0; i < n; i++)”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么 8 个变量、a[1] 当第一个、或 a[n] 不对；**看最后一个之后必须亲手写出 `a[n - 1]` 才能进入任务 3**，空提交给出“先写下写法”的指正，全角符号提示“方括号要用半角 [ ]”，`a[n]`/`a[n + 1]`/`a[3]` 直接点出越界原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；格子卡片从“还没开始走”变为“a[0] = 3”，再变为“a[1] = 8”，再变为“a[3] = 2”；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。vector 只作为拓展出现。

补充：点击尚未点亮的任务或跳过“看 a[0]”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S2-01-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S2-01-03 恢复与降级

1. 完成任意任务、在访问最后一个成绩的框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认数组写法选择、下标走格流程、**`a[n - 1]` 草稿和完成状态**都恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S2-01-04 常见问题解惑

1. 在任务 1 点击带虚线的 `数组` 或 `下标`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，点击 `长度` 或 `越界`。
4. 再点右上角“常见问题”，切换到 `数组初始化`。

**预期：** 解释只用初学者能懂的话；不要求背完整数组标准；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。

## 自动化复验记录

E2E-S2-01-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
bun run e2e:s2-typed
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。脚本一次覆盖全部 24 节已迁移课（S2-01 至 S2-08、S3-01 至 S3-08、S4-01 至 S4-08），每课 14 项检查；`CSP_E2E_LESSONS=s2-01 bun tests/e2e/s2-typed-cdp.ts` 可以只跑本课。
