# S5-07 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s5-07/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s5-07-progress-v1` 后刷新。

## E2E-S5-07-01 先选出该怎么开始

1. 在任务 1 为“这次模拟赛用的是三道全新的题目 T4、T5、T6，总时长依旧 120 分钟。开始前，比较合理的准备方式是什么？”选择“先看一眼上一次（S5-05）的自测表和时间记录，把已经确定要用的习惯（比如先排提交顺序）带到这次”，为“这次又做到了‘先排提交顺序’。要判断这个习惯是不是已经稳定，应该怎么做？”选择“和上一次的记录做交叉检查：确认这次是不是又独立做到了同一个具体行为，两次都做到才记为稳定”。先故意选一个错误说法（例如“题目全是新的，之前的记录都用不上，直接从头摸索”），确认能看到风险提示。
2. 在任务 2 依次点击“独立解题：完成新题组”“交叉检查：对照上一次记录”“习惯记录：写下稳定与否”。尝试跳过第一步直接点第二、三步。
3. 在任务 2 出现的只读脚手架里亲手补空：程序已经用累加法算出 1 到 n 的和，那一格要用另一条独立公式再手算一遍对账（n ≤ 100000）。先空着点“检查这一空”，再输入全角写法 `long long formula ＝ 1LL ＊ n ＊ （n ＋ 1） ／ 2；`，再分别输入 `long long formula = (n + 1) / 2 * n;`（先除会丢小数）、`long long formula = n * n / 2;`（少了 `(n + 1)`）和漏掉 `1LL` 的写法，最后写对 `long long formula = 1LL * n * (n + 1) / 2;`。
4. 在任务 3 先选择对照两次时间分配的正确做法（“把这次每题用时和上一次并排列出来比较……”），再选择习惯这次没做到时的正确记录方式（“如实标注这个习惯还没有稳定，需要再做一次独立验证……”）。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项都有对应的风险说明（例如从头摸索浪费已验证的习惯、只做一次就宣布稳定、凭感觉判断、跳过独立解题直接照抄、只凭印象比较用时、顺便算作稳定或直接放弃练习）；对照卡片从“还没开始独立解题”依次变为“已完成独立解题”“已交叉检查”“已写下稳定习惯记录”；页面标明必会、建议掌握和拓展；手写那一空答对后给出“进入任务 3”的反馈；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。

补充：任务 2 三步没点完时输入框不出现；点击尚未点亮的任务，或跳过“独立解题：完成新题组”“交叉检查：对照上一次记录”直接点“习惯记录：写下稳定与否”时，页面必须解释当前缺少哪一步，不能无反馈；三步走完并且那一空答对之后，任务 3 才点亮，任务 3 两个选择都答对后任务 4（随机小测）才点亮。空提交、全角符号、漏掉 `long long formula =` 声明或末尾分号、先除后乘、少了 `(n + 1)`、漏掉 `1LL`，都只给具体指正，不算完成；写成交换乘法次序的 `1LL * (n + 1) * n / 2` 算答对，并提示乘法交换不影响结果。

## E2E-S5-07-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题（本课题库 7 题全部为选择题）；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S5-07-03 恢复与降级

1. 完成任意任务、写好那一空或选择部分小测答案后刷新页面。
2. 回到当前任务，确认状态选择、三步操作、手写填空答案和答题恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、手写填空的草稿与完成状态、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S5-07-04 常见问题解惑

1. 在任务 1 或任务 2 点击带虚线的 `新题组`、`交叉检查`、`对照上一次`或`稳定习惯`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，确认页面仍可继续，并在脚手架旁点击 `long long`、`溢出`。
4. 再点右上角“常见问题”，切换到其余词条。

**预期：** 解释只用初学者能懂的话；不要求背复杂度证明或竞赛级优化技巧。外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题；词条载入失败时会明确说明，且不影响继续做题。

## 自动化复验记录

E2E-S5-07-01 中的手写填空部分可以在真实浏览器中自动重跑一遍，不需要人工点击：

```bash
CSP_E2E_LESSONS=s5-07 bun tests/e2e/s2-typed-cdp.ts
```

脚本会自行启动开发服务器（`bun scripts/dev.ts`）和无头 Chrome，结束后关掉自己启动的进程并删除临时配置目录。它需要本机装有 Chrome；若换成别的可执行文件路径，用 `CSP_E2E_CHROME` 指定。它不属于 `bun test`：断言依赖真实浏览器渲染，属于体验验收而不是单元测试。`bun run e2e:s5-typed` 会一次覆盖 S5-01 至 S5-08 八课（112 项检查），`bun run e2e:typed` 覆盖全部 32 节已迁移课（448 项检查）。
