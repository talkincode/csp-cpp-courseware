# S4-04 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s4-04/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s4-04-progress-v1` 后刷新。

## E2E-S4-04-01 引导任务推进

1. 在任务 1 为“搜索题在本课要做什么？”选择“对每个数分别选或不选，画出搜索树，把可能的方案都试一遍”，为“剪枝要怎么处理？”选择“当前和已经超过 target 时立刻停止这条分支，不再往下选”。先故意选一个错误说法。
2. 在任务 2 依次点击“选择：把 1 加入集合”“剪枝判断：sum 是否超过 target”“回溯：撤销选择，继续搜索”。尝试跳过第一步直接点第二步。
3. 走完“回溯：撤销选择，继续搜索”之后，在露出的一空里亲手敲入剪枝那一行并点检查。先试空提交、全角符号 `if （sum ＞ target） return；`、以及 `if (sum >= target) return;`（刚好等于 target 也会被剪掉）、`if (sum < target) return;`（方向写反）、`if (sum > target) break;`（写成了 break）、`if (sum + a[i] > target) return;`（a[i] 会重复加），再用“查看提示”和“参考代码”对照。此时任务 3 仍未点亮。
4. 在任务 3 先选择一个错误说法，再选择“对每个数按顺序选或不选，递归到底后判断 sum 是否等于 target，处理完就撤销继续下一种”，以及“n=1 时只判断这一个数是否等于 target；所有数都试完仍未命中时，无解并回溯到上一层”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；**走完第三步之后必须亲手写出 `if (sum > target) return;` 才能进入任务 3**，空提交给出“先在空里写出剪枝那一行”的指正，全角符号提示“都要敲半角”，`if (sum >= target) return;`（边界差一点）、`if (sum != target) return;`（把所有解都丢了）、`if (sum < target) return;`（方向反了）、`if (sum > target) break;`（break 只能跳出循环）、`if (sum + a[i] > target) return;`（a[i] 重复加）、`if (sum > n) return;`（比错对象）都会各自被点出原因；“查看提示”给渐进线索、“参考代码”可展开收起且不自动填答案、“重置”清空这一空与草稿；错误选项解释为什么不要先写完整程序再猜搜索树长什么样、剪枝不能等提交前再补、图的最短路是拓展、排序不是必须步骤、评测机不会替你剪枝；对照卡片从“还没开始搜索”变为已选择集合 {1}，再变为已判断剪枝，最后变为集合 {1, 3}、sum=4、命中并回溯；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。多维状态剪枝、双向搜索、记忆化只作为拓展出现。

补充：点击尚未点亮的任务或跳过“选择：把 1 加入集合”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。输入框内容只做字符串比较，用 `<script>x</script>` 这类内容提交不会被执行，也不会被当作正确写法。

## E2E-S4-04-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都把检查目标绑到本课学习目标原文、另起一行写出本题检查、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S4-04-03 恢复与降级

1. 完成任意任务或选择部分小测答案后刷新页面。
2. 回到当前任务，确认搜索思路选择、三步操作和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S4-04-05 常见问题解惑

1. 在任务 1 点击带虚线的 `搜索树` 或 `剪枝`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 2，确认页面仍可继续。
4. 再点右上角“常见问题”，切换到 `深度优先搜索` 或 `回溯`。

**预期：** 解释只用初学者能懂的话；不要求背图上的完整 DFS/BFS 或状态压缩细节；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
