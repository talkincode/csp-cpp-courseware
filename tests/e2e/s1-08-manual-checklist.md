# S1-08 手工端到端验收

在仓库根目录运行 `bun run dev`，打开 <http://localhost:4173/lessons/s1-08/>。如需从头开始，删除浏览器本地存储键 `csp-cpp-s1-08-progress-v1` 后刷新。

## E2E-S1-08-01 引导任务推进

1. 在任务 1 为“少写分号，编译器直接拒绝”选择“编译错误”，为“程序编译成功，却在除以 0 时停住”选择“运行错误”。先故意选一个错误类型。
2. 在任务 2 依次点击“读报错”“点到那一行”“确认类型”，然后在露出的一空里亲手敲入半角分号并点检查。先试空提交和中文分号。尝试跳过读报错直接点“点到那一行”。
3. 在任务 3 先选择一个错误说法，再选择“先用 n = 1 这种最小数据”，以及“用 cout 打印中间值”。

**预期：** 每一步都显示即时文字反馈；下一任务仅在前一任务完成后点亮；错误选项解释为什么分类或检查顺序不对；确认类型后必须亲手补上分号才能进入任务 3，空提交与中文符号都有指正；定位卡片从“还没开始查”变为“expected ';'”，再变为“cout << n”，再变为补上分号后的确认；页面标明必会、建议掌握和拓展；正确完成会出现奖励提示，音效关闭时仍有完整视觉反馈。页面不运行学习者提交的 C++，也不加载视频。gdb 只作为拓展出现。

补充：点击尚未点亮的任务或跳过“读报错”直接点击第二步时，页面必须解释当前缺少哪一步，不能无反馈。

## E2E-S1-08-02 随机小测与解析

1. 进入“随机小测”，确认显示本次试卷标识和 3 道选择题。
2. 不作答时确认提交按钮不能提交；选择三题答案后提交。
3. 阅读每题解析和总分。
4. 点击“换一套题”。

**预期：** 单次试卷题目不重复；每题都有课程目标、四个选项、一个正确答案和解析；选择题数量多于非选择题；提交后显示逐题正误与得分；换题后试卷标识变化且不保留上一套答案。题库来源为本课 course-plan / 自编，并标记待人工审校。

## E2E-S1-08-03 恢复与降级

1. 完成任意任务、在补分号框里敲字或选择部分小测答案后刷新页面。
2. 回到当前任务，确认错误分类、语法定位流程、补分号草稿和答案恢复。
3. 在禁止站点存储的浏览器环境中重复一次操作。

**预期：** 正常环境能恢复任务、试卷与答案；存储不可用时页面明确说明“刷新后不会恢复进度”，页面不会卡住或伪造保存成功。

## E2E-S1-08-04 常见问题解惑

1. 在任务 1 点击带虚线的 `编译错误` 或 `运行错误`。
2. 确认侧栏出现基础解释、一句“现在记住”和至少一个外部链接。
3. 关闭后进入任务 3，点击 `答案错误` 或 `分段输出`。
4. 再点右上角“常见问题”，切换到 `缩进` 或 `命名`。

**预期：** 解释只用初学者能懂的话；不要求背完整调试器手册；外部链接在新标签打开。词条以小卡片出现，不挡住任务按钮；点遮罩、“关闭”或“继续学习”后可立刻继续做题。
