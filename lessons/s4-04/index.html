这一课只练一件事：把每一步的选择画成 ，用 逐条走完。必会：判断安全的 条件、写完一条分支后正确 、写出停止搜索的边界。最小示例：从 3 个数 1、2、3 中选出若干个，使它们的和恰好等于 target = 4；每个数只能选或不选，1 <= n <= 20。样例追踪：选 1、跳过 2、选 3，和为 1 + 3 = 4，命中后记录方案并回溯，继续尝试其他组合。边界是 n=1（只判断这一个数是否等于 target），以及所有数都试完仍未凑出 target（无解，回溯到底）。建议掌握：统计一共找到几种方案。多维状态剪枝、双向搜索、记忆化是拓展。这里不会在浏览器里运行 C++。

三步走完了，现在把搜索树上的判断落成一行代码：数字都是正数，一旦当前和超过 target，这条分支就不可能再凑出来，用 把它停掉。下面是只读脚手架，只留一空给你敲键盘；这里不会在浏览器里运行 C++。

  1. // a[1..n] 是候选数字，ans 统计能凑出 target 的方案数
  2. int a[25], n = 3, target = 4, ans = 0;
  3. void dfs(int i, int sum) {
  4. if (sum == target) { ans += 1; } // 刚好凑出 target：记下一种方案
  5. if (i > n) return; // 数字都试完了，这条分支结束
  6. // 剪枝：再往下选只会更大，先停
  7. dfs(i + 1, sum + a[i]); // 选第 i 个数字
  8. dfs(i + 1, sum); // 不选第 i 个数字
  9. }
