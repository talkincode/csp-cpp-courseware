必会：能把小数排成从小到大。边界：只比较不相邻的 3 和 2，会漏掉中间的 1；要先比 a[0] 和 a[1]。

  1. int a[3] = {3, 1, 2};
  2. if (a[0] > a[1]) swap(a[0], a[1]); // 得到 1, 3, 2
  3. if (a[1] > a[2]) swap(a[1], a[2]); // 得到 1, 2, 3
  4. // 现在已经从小到大
