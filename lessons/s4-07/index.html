三步走完了，现在把“防止重复访问”落成一行代码：dfs 走到一个点 u 时，先看它来过没有——来过就马上结束这次调用，别再往下走。 这种类型只有 true 和 false 两个值，正好用来当访问标记。下面是只读脚手架，只留一空给你敲键盘；这里不会在浏览器里运行 C++。

  1. // 最小示例：5 个点（0~4），边 (0,1) (1,2) (3,4)，这是无向图
  2. int adj[1005][1005]; // 邻接表（数组版）：adj[u][k] 是 u 的第 k 个邻居
  3. int deg[1005]; // deg[u] 记录 u 有几个邻居
  4. bool visited[1005]; // 访问标记：false 表示还没来过，true 表示来过了
  5. void dfs(int u) {
  6. // 来过就收工，别再往下走
  7. visited[u] = true; // 登记：这个点来过了
  8. for (int k = 0; k < deg[u]; k += 1) dfs(adj[u][k]); // 再把每个邻居都走一遍
  9. }
  10. // 数连通块：for (int i = 0; i < n; i += 1) if (!visited[i]) { dfs(i); pieces += 1; }

任务 3：确定 DFS/BFS 的顺序差异，并认出两个边界

建议掌握：DFS 沿一条路径尽量走到底再回头（用递归或栈），BFS 按“一层一层”向外扩展（用队列），得到的是离起点的最短步数层级；这两种顺序本质不同，不能混为一谈。拓展：BFS 的层数可以当作“最短步数”的初步认识，现在只用认识这个概念。
