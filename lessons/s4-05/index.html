任务 2：按排序、扫描、记录三步统计出现次数

最小示例：6 名学生成绩 90 78 85 90 85 90，要统计出现次数最多的分数。按顺序点三步：先 把分数排好，再顺序扫描，累计连续相同的次数（这一步在处理 ），最后记录当前出现次数最多的分数。这里不会在浏览器里运行 C++。

必会：能解释每一步为什么这样做。边界：不要跳过“扫描”直接猜答案。排序后如果还要按分数查某个具体值是否存在，可以直接复用 ，不用重新写一遍扫描逻辑。

  1. // 排序：90 78 85 90 85 90 → 78 85 85 90 90 90
  2. // 扫描：78(1 次) 85(2 次) 90(3 次)，相邻相同就累加，不同就重新计数
  3. // 记录：90 的连续次数 3 大于已记录的最高频，更新最高频分数为 90
  4. // 若需查某个具体分数是否存在，可复用二分查找
