这一课只练一件事：用按证据修错，而不是靠猜测乱改。顺序是先做，再用或检验假设，最后记下修复原因并重新测试。必会：能把错误缩小到小数据；能写出验证假设的输出；不靠乱改碰运气。最小示例：求前缀和的程序对 n=5 错了，先缩成 n=2 仍错。样例追踪：n=5 输出 9，手算应是 10；缩到 a=[1,2] 仍少 1；分段输出发现 prefix 从 a[1] 开始加。边界是不要在大数据上猜改，也不要改完不回归。建议掌握：写下修复原因。拓展：用暴力程序做只是拓展习惯，现在不当硬门槛。这里不会在浏览器里运行 C++。

任务 2：按缩小、分段输出、回归三步走完修错卡

最小示例：求前缀和的程序对 n=5 输出 9，手算应是 10。按顺序点三步：先做，再，最后记下原因并用原样例和反例回归。这里不会在浏览器里运行 C++。

必会：能解释每一步为什么这样做。边界：不要在 n=100000 上猜改；不要改完不回归。

  1. // 现象：n=5，a=[1,2,3,4,5]，输出 9，手算应是 10
  2. // 缩小：试 a=[1,2]，输出 2，手算应是 3，错误仍在
  3. // 分段输出：打印 i 和 prefix，发现循环从 i=1 开始，漏了 a[0]
  4. // 回归：记下“少加了 a[0]”，再用原样例和这组反例复测

还没开始缩小错误范围
先点“缩小：把 n=5 的错误缩到 n=2 仍错”。

三步走完了，现在把“分段输出”落成一行代码：在循环里把这一轮的轮次 i 和当前算出来的和 prefix 都打到屏幕上，再和手算对照。下面是只读脚手架，只留一空给你敲键盘；这里不会在浏览器里运行 C++。

  1. // 现象：n=5，a=[1,1,2,3,3]，手算应是 10，程序却输出 9
  2. int a[5] = {1, 1, 2, 3, 3};
  3. int prefix = 0; // prefix：加到这一轮为止的和
  4. int main() {
  5. for (int i = 1; i <= 4; i += 1) { // 可疑：这一轮该从哪里开始加？
  6. // 分段输出：把 i 和 prefix 都打出来
  7. prefix += a[i];
  8. }
  9. cout << prefix << "\n"; // 输出 9
  10. return 0;
  11. }

        cout << i << " " << prefix << "\n";   // 每一轮各占一行，才好和手算对照
