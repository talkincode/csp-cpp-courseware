任务 1：先找到程序的“开门钥匙”

你看到的每一行都有用，但程序真正从 开始执行。先点击按钮，把入口这一行点亮。遇到不认识的词，点它或点右上角“常见问题”。

  1. #include <iostream>
  2. int main() {
  3. std::cout << "Hello, CSP!" << "\n";
  4. return 0;
  5. }
头文件 让程序能使用输入输出工具。
入口 是程序开始工作的地方。
输出 把文字或结果显示到屏幕。

必会：#include、main、cout 这三个词现在就要记住它们各自的角色；先认清它们，后面的课才好往下走。

任务 2：程序不是写完就会自己运行

电脑先看到的是给人看的 ；会把它翻译成电脑可以运行的程序。按从左到右的顺序点亮流程。后面出现的 只是这个翻译工具的名字。

必会：写源文件 → 编译 → 运行的顺序不能颠倒，这是必会。建议掌握：知道 g++ 是常见编译工具的名字，属于建议掌握，暂时不需要记住它的具体参数。

这是概念演示，不会在浏览器里运行 C++，也不是真正的在线编译器。 真实的 C++ 编译会在你的电脑工具中完成；这里帮你记住正确流程。拓展：在自己电脑上安装、配置 g++ 属于拓展内容，本课不要求。

任务 3：修好第一个“少了分号”的程序

C++ 中多数一行指令都要用 结束。下面这段代码在输出行少了一个分号；选出最小、最准确的修复方式。

必会：看到编译报错先找“少了分号”这类最常见原因，再动手改最小的一处，不要整段重写。

  1. #include <iostream>
  2. int main() {
  3. std::cout << "Hello, CSP!" << "\n"
  4. return 0;
  5. }

选对了。现在亲手把这个分号敲进去：下面是只读脚手架，只留一空给你敲键盘。

  1. std::cout << "Hello, CSP!" << "\n"

std::cout << "Hello, CSP!" << "\n";
