任务 2：按顺序拆开 125

最小示例：x % 10 取出个位，x / 10 去掉个位。按顺序点三步，把 125 拆成 5、2、1。这里不会在浏览器里运行 C++。

必会：能拆分一个三位数。边界：最后一次 1 / 10 得到 0，循环必须停；不要跳过中间的 12。

  1. int x = 125;
  2. int digit = x % 10; // 5
  3. x = x / 10; // 12
  4. while (x > 0) { /* 继续剥，直到 x 变成 0 */ }

任务 3：用余数求 GCD，并看循环何时停

建议掌握：求 用辗转相除，和拆数位一样靠余数。必会还包括解释循环何时结束：余数变成 0。 是每一轮都成立的关系。

  1. int a = 12, b = 8;
  2. int r = a % b; // 12 % 8 = 4
  3. a = b; b = r; // 换成 8 和 4
